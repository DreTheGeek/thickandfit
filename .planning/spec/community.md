# Living Spec: Community (REQ-COMM-*)

## REQ-COMM-001: Feed
THE SYSTEM SHALL provide a feed with posts, photos, videos, reactions, and comments, scoped by group.
Added by: PRD-26 | Status: planned

## REQ-COMM-002: Groups
THE SYSTEM SHALL support groups with membership management, migrated from Lenus groups.
Added by: PRD-26 | Status: planned

## REQ-COMM-003: Direct messages
THE SYSTEM SHALL support 1:1 DMs (subscriber-coach, subscriber-AI, subscriber-subscriber) with
read receipts and media, gated by coach settings.
Added by: PRD-27 | Status: planned

## REQ-COMM-004: Challenges + leaderboards
THE SYSTEM SHALL run challenges with live leaderboards and prizes, enrolled via cohort SKUs.
Added by: PRD-28 | Status: planned

## REQ-COMM-005: Coach broadcasts
WHEN a coach sends a broadcast THE SYSTEM SHALL deliver to a segmented audience in each
recipient's language with personalization tokens.
Added by: PRD-29 | Status: planned
