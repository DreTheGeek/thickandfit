# Living Spec: Admin (REQ-ADM-*)

## REQ-ADM-001: Client list + profiles
THE SYSTEM SHALL provide a coach client list and 7-tab client profiles mirroring Lenus IA.
Added by: PRD-07 / PRD-33 | Status: planned

## REQ-ADM-002: Multi-form builder
WHEN a coach builds a form THE SYSTEM SHALL support text, multiline, select, rating, sleep,
photo, and measurement blocks, publishable to clients.
Added by: PRD-04b | Status: planned

## REQ-ADM-003: Mid-ticket workflow
THE SYSTEM SHALL route mid-ticket clients to a PT assistant inbox with a Stephanie last-eyes
approval gate before publish.
Added by: PRD-30 | Status: planned

## REQ-ADM-004: User feedback inbox
THE SYSTEM SHALL collect client feedback (1-5 stars + text) and surface it to the coach.
Added by: PRD-40 | Status: planned

## REQ-ADM-005: Analytics
THE SYSTEM SHALL show engagement, financial, and retention analytics to the coach.
Added by: PRD-41 | Status: planned
