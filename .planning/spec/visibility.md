# Living Spec: Visibility (REQ-VIS-*)

## REQ-VIS-001: Technical SEO
THE SYSTEM SHALL ship robots.txt, sitemap.xml, canonical URLs, and per-page metadata on all
public surfaces.
Added by: PRD-43 | Status: planned

## REQ-VIS-002: Schema markup
Public pages SHALL render SoftwareApplication, Organization, and FAQPage JSON-LD.
Added by: PRD-43 | Status: planned

## REQ-VIS-003: Bing + IndexNow
THE SYSTEM SHALL enable IndexNow and submit to Bing Webmaster Tools (the ChatGPT pipeline).
Added by: PRD-43 | Status: planned

## REQ-VIS-004: Pre-registration waitlist
THE SYSTEM SHALL capture pre-launch emails with a lead magnet and enroll them in a GHL drip.
Added by: PRD-03 | Status: planned
