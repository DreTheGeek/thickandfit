# Living Spec: Workout (REQ-WORK-*)

## REQ-WORK-001: Exercise library
THE SYSTEM SHALL provide a searchable library of exercises with muscle group, equipment,
difficulty, bilingual names, and video demos.
Added by: PRD-08 | Status: planned

## REQ-WORK-002: 5-context substitution
WHEN a client selects an equipment context THE SYSTEM SHALL offer coach-curated substitutes with
reason tags.
Added by: PRD-09 | Status: planned

## REQ-WORK-003: Program builder
WHEN a coach builds a program THE SYSTEM SHALL persist sessions, circuits, supersets, rest, and
instruction notes and allow assignment to a client.
Added by: PRD-10 | Status: planned

## REQ-WORK-004: Workout player
WHEN a client runs a workout THE SYSTEM SHALL play an audible interval timer, hold a Wake Lock so
the screen does not dim, and stream demo video reliably.
Added by: PRD-11 | Status: planned

## REQ-WORK-005: Progressive overload
WHEN a client completes a session and rates difficulty THE SYSTEM SHALL recommend next-session
weight/reps from the last 4 sessions.
Added by: PRD-11 | Status: planned

## REQ-WORK-006: Workout logging
WHEN a client logs sets/reps/weight THE SYSTEM SHALL persist them and surface history to the coach.
Added by: PRD-12 | Status: planned
